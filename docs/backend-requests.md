# Запросы фронтенда к бэкенду

Сюда фронтенд-сессия записывает, что ей нужно от бэкенда (новые поля, эндпоинты, правки ошибок, документы). Бэкенд-сессия читает файл, делает или комментирует, и переносит итог в `docs/frontend-contract.md` бэкенда. Выполненное убирать в «Сделано».

Формат записи:

```
### Короткое название
- Зачем: что не получается сделать на фронте без этого
- Что нужно: поле / эндпоинт / поведение
- Статус: ожидает | в работе | сделано (дата)
```
